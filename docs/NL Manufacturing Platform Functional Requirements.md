# NL Manufacturing Platform Functional Requirements

Oct 23, 2026

This document lists every functional requirement for the MVP. Each requirement has a code, a description, a priority (Must / Should / Could), and an acceptance criterion. Requirements are grouped by system module.

All generated text follows [Standard Generated English (SGE)](https://github.com/WeirdCatAFK/SGE). SGE is an approximation of ASD-STE100 for text and code comments that AI agents write.

## Constraint check engine (FR-CCE)

| Code       | Description                                                                                                                                                 | Priority | Acceptance criterion                                                                                         |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| FR-CCE-001 | The engine must run after every geometry generation cycle, before the DFM reviewer.                                                                         | Must     | The generation pipeline calls the engine and waits for its report before calling the DFM reviewer.           |
| FR-CCE-002 | The engine must check that every bolt hole diameter matches the standard parts library value for the specified bolt size.                                   | Must     | An M3 clearance hole that is not 3.2 mm triggers an error.                                                   |
| FR-CCE-003 | The engine must check that every board mounting hole position matches the relevant board specification.                                                     | Must     | ATX standoff positions that do not match the ATX spec trigger an error.                                      |
| FR-CCE-004 | The engine must check that every mating surface has matching dimensions within the stated tolerance.                                                        | Should   | Two parts that connect but have mismatched hole spacing trigger an error.                                    |
| FR-CCE-005 | The engine must check minimum wall thickness (1.2 mm for FDM, 0.8 mm for SLA).                                                                              | Must     | A wall below the minimum triggers an error with the measured value and the minimum.                          |
| FR-CCE-006 | The engine must check maximum overhang angle (45 degrees for FDM without support).                                                                          | Must     | An overhang above 45 degrees triggers a warning.                                                             |
| FR-CCE-007 | The engine must check that part dimensions fit within the stated build volume.                                                                              | Must     | A part that exceeds the build volume triggers an error.                                                      |
| FR-CCE-008 | The engine must check minimum hole diameter (2.0 mm for FDM).                                                                                               | Should   | A hole below 2.0 mm triggers a warning.                                                                      |
| FR-CCE-009 | The engine must check minimum feature size for laser cutting (1.0 mm for acrylic, 0.5 mm for plywood).                                                      | Must     | A feature below the minimum triggers an error.                                                               |
| FR-CCE-010 | The engine must check kerf compensation on all laser-cut paths.                                                                                             | Must     | Paths without kerf compensation trigger an error.                                                            |
| FR-CCE-011 | The engine must check minimum distance between laser cuts (2.0 mm).                                                                                         | Should   | Cuts closer than 2.0 mm trigger a warning.                                                                   |
| FR-CCE-012 | The engine must check that every part in the assembly manifest has at least one connection to another part.                                                 | Must     | An isolated part triggers a warning.                                                                         |
| FR-CCE-013 | The engine must check that fastener holes align between mating parts within tolerance.                                                                      | Must     | Misaligned holes trigger an error with the measured offset.                                                  |
| FR-CCE-014 | The engine must check for bounding-box overlap between solid parts in the assembly.                                                                         | Should   | Two parts that overlap trigger a warning.                                                                    |
| FR-CCE-015 | The engine must produce a validation report with pass count, fail list (rule, measured value, expected value, file, line), and severity (error or warning). | Must     | The report is a structured JSON file that the orchestrator can parse.                                        |
| FR-CCE-016 | Error-level failures must go back to the geometry generator as feedback. The generator must fix them before the DFM reviewer receives the design.           | Must     | The orchestrator does not call the DFM reviewer until all errors are resolved or the cycle limit is reached. |
| FR-CCE-017 | The engine must check that no unsupported bridge is longer than 10 mm (FDM).                                                                                | Should   | A bridge longer than 10 mm without support triggers a warning.                                               |
| FR-CCE-018 | The engine must check that laser-cut part dimensions fit within the stated bed size.                                                                        | Must     | A part that exceeds the bed size triggers an error.                                                          |
| FR-CCE-019 | The engine must check that the material thickness is within the limit of the stated laser cutter.                                                           | Should   | A material thickness above the cutter limit triggers an error.                                               |
| FR-CCE-020 | Warning-level failures must go to the DFM reviewer. The reviewer must accept or reject each warning.                                                        | Must     | The DFM reviewer report lists each warning with a decision and a reason.                                     |
